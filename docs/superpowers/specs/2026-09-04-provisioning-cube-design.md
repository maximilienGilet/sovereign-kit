# Provisioning cube refinement

Approved direction: replace the orbital sphere with the README's isometric
outer cage and suspended inner cube. Keep geometry stationary; animate cyan
edge lighting, core pulse and a brief stage-change flash. Preserve the active
label shimmer.

On wide terminals, center a bounded composition with the cube left and a
left-aligned status/timeline right. Keep instance identity and billing beneath
that composition; keyboard controls remain at the terminal bottom. On narrower
terminals stack when space permits, otherwise preserve text before decoration.

Use the existing Bubble Tea clock, epoch fencing, Bubbles spinner and Lip Gloss
layout. No new dependencies. NO_COLOR disables chromatic effects. Error states
freeze the cube and retain recovery controls. Do not change provider lifecycle,
timeouts, paid creation, destruction confirmation or real infrastructure.

Acceptance: stable cube geometry across animation frames, visible moving color,
aligned timeline, bounded render at 30×10 and wider sizes, existing safety tests
pass. Verify with an in-memory fake provider only.

Implemented in provisioning_cube.go, provisioning_loader.go and
application_view.go. The user explicitly requested realization of this agreed
direction; no new design choice or provider operation was introduced.
